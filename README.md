# wardrobe-lord

A single-page wardrobe map: tap an area on the cupboard to see what's in it, with photos.

Open `index.html` in any browser, or host it with GitHub Pages (see below).

## Notes
- Everything lives in `index.html` (no build step, no dependencies except Google Fonts).
- Edits you make in the page are saved in your own browser (localStorage) only. To make a change permanent for everyone, update `SAVED` in `index.html` and bump `SAVED_VERSION`.
- The file contains photos of your clothes and cupboard embedded inside it. Keep the repository **private** if you don't want them public.
